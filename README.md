# TôlerieCAD — téléchargement

Logiciel de **tôlerie et de chaudronnerie** pour Windows : dépliage de pièces 3D (STEP), repliage de développés DXF,
pièces types (rond-carré, cône, virole, trémie, cornière, U, bac), cotation et mesure, texte pour découpe laser,
retour élastique et ordre de pliage à la presse plieuse. Interface en français, anglais, espagnol, russe et arabe.

## Installer

**[⬇ Télécharger TôlerieCAD pour Windows](../../releases/latest/download/TolerieCAD-Setup.exe)** (Windows 10 / 11, 64 bits)

1. Lancez `TolerieCAD-Setup.exe`. Si Windows affiche « Windows a protégé votre ordinateur » :
   *Informations complémentaires* → *Exécuter quand même*.
2. L'installation ne demande pas de droits administrateur (au choix).
3. Essai gratuit de 30 jours, puis licence : *Fichier → Licence…* affiche le code machine à nous envoyer.
